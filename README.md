# SDET Automation Challenge

This repository contains a comprehensive test automation framework built to satisfy the requirements of the technical assessment. It demonstrates modern testing best practices, stable locator strategies, and seamless UI/API test integration.

## 🚀 Features & Scope

### 💻 Challenge 1: UI Test Automation
* **Target:** [Demoblaze](https://www.demoblaze.com)
* **Scenarios Covered:** * End-to-end user purchase flow (laptop category selection, cart persistence, and dynamic modal checkout form).
  * Cart state management and dynamic price recalculation upon item removal.

### 🌐 Challenge 2: API Test Automation
* **Target:** [Thinking Tester Contact List](https://thinking-tester-contact-list.herokuapp.com/)
* **Scenarios Covered:** * Dynamic user registration, authentication token capturing, and profile validation.
  * Full lifecycle RESTful CRUD operations (`POST`, `GET`, `PUT`, `DELETE`) on protected Contact endpoints.
* **Patterns Used:** Isolated runtime request contexts, dynamic payload generation, and negative schema validation (404 verification post-deletion).
